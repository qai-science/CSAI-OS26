# CSAI-OS26 — Operating Systems Lab Code

Runnable C programs for the Operating Systems course (2026). Each folder is one topic and builds with `make` on any Linux machine.

| Folder | Topic |
|---|---|
| [pipes-namedpipes-sharedmemory](pipes-namedpipes-sharedmemory/) | 3.3 Shared Memory, Pipes and Named Pipes in Linux |

Setup on Ubuntu:

```bash
sudo apt install -y build-essential
git clone https://github.com/qai-science/CSAI-OS26.git
```
