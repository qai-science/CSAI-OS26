# CSAI-OS26 — Operating Systems Lab Code

Runnable C programs for the Operating Systems course (2026). Each folder is one topic and builds with `make` on any Linux machine.

| Folder | Topic |
|---|---|
| [pipes-namedpipes-sharedmemory](pipes-namedpipes-sharedmemory/) | 3.3 Shared Memory, Pipes, Named Pipes and Semaphores in Linux · [interactive simulation](https://qai-science.github.io/CSAI-OS26/pipes-namedpipes-sharedmemory/simulation/) |
| [critical-section](critical-section/) | 3.7–3.10 Critical section: race, Peterson, TestAndSet, Swap, mutex, binary semaphore · [interactive simulation](https://qai-science.github.io/CSAI-OS26/critical-section/simulation/) |
| [monitors-and-algorithms](monitors-and-algorithms/) | 3.11–3.15 Monitors, Algorithm 1, 2, Peterson, Bakery · [interactive simulation](https://qai-science.github.io/CSAI-OS26/monitors-and-algorithms/simulation/) |

Setup on Ubuntu:

```bash
sudo apt install -y build-essential
git clone https://github.com/qai-science/CSAI-OS26.git
```
